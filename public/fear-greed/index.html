Fear & Greed Index FAQ

Fear & Greed Index 日本版は、米国で広く知られる恐怖・貪欲指数の考え方を日本市場に応用した、独自の投資家心理指標です。本サイトは独立した個人プロジェクトであり、CNN等のメディア企業とは一切関係ありません。

7つの市場指標を分析し、投資家が「恐怖（Fear）」と「貪欲（Greed）」のどちらにより強く動かされているかを 0〜100 のスコアで表します。スコアが低いほど投資家の恐怖が強く、高いほど貪欲であることを示します。

以下の7つの指標を個別にスコアリングし、均等加重平均で総合スコアを算出しています：

  1. 市場モメンタム：日経225と125日移動平均の乖離率
  2. 株価の強さ：52週高値/安値近辺にある銘柄数の比率
  3. 騰落レシオ：上昇銘柄数と下落銘柄数の比率
  4. プット・コール比率：オプション市場から推計される弱気度
  5. 市場ボラティリティ：日経VIとその50日移動平均
  6. 安全資産需要：日本国債 vs 株式の20日リターン比較
  7. 社債需要：社債 vs 安全資産のリターン差
スコア範囲 状態 意味
0〜25 極度の恐怖 投資家が過度に悲観的。逆張りの買い機会の可能性
25〜45 恐怖 投資家が慎重。市場に不安感が漂う
45〜55 中立 市場心理がバランスしている状態
55〜75 貪欲 投資家が楽観的。リスク選好が高まる
75〜100 極度の貪欲 市場が過熱。調整リスクに注意

本指標は Yahoo Finance API (yfinance) を通じて取得した日本市場のデータを使用しています。主なデータソース：

  • 日経225指数 (^N225)
  • 日経VI ボラティリティ指数
  • 東証上場主要銘柄30社の株価データ
  • 国内債券ETF (2510.T)
  • 社債ETF (1496.T)
